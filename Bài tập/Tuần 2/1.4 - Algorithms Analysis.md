## 1.4.17 - Farthest Pair
Trong một dãy số, hiệu (lấy giá trị tuyệt đối) lớn nhất giữa hai phần tử là hiệu của số lớn nhất và số bé nhất

    => Tìm số lớn nhất và bé nhất.
```
public class FarthestPair {
    public static void findFarthestPair(double[] a) {
        if (a == null || a.length < 2) return;

        double min = a[0];
        double max = a[0];

        for (int i = 1; i < a.length; i++) {
            if (a[i] < min) min = a[i];
            if (a[i] > max) max = a[i];
        }

        double maxDiff = max - min;
        System.out.println("Cặp xa nhất: " + min + " và " + max + " (Hiệu: " + maxDiff + ")");
    }
}
```
